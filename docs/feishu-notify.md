# 飞书提醒（简易版）

固件 0.5.31 新增，App 编号 49（`App::Feishu`），在菜单「电脑 · 时间」页第一个。菜单图标是仿飞书的蓝色鸟形（白底，`generate_passport_font.py` 画的 U+E00D）。需要 Mac 助手 0.1.10。

## 原理

不用飞书开放平台，不建应用，也不用管理员审批。Mac 版飞书（Lark.app，bundle `com.electron.lark`）来消息时会发系统通知，macOS 把通知存在 `~/Library/Group Containers/group.com.apple.usernoted/db2/db`。助手每 2 秒读一次里面飞书的新通知，取出发送人（`titl`）、副标题（`subt`，群里可能是发言人）和消息开头（`body`），推给胸牌。

- 只读，不发消息，也不碰飞书客户端。
- 消息只放在助手内存里（最近 100 条），不写硬盘。设置网页和诊断信息里不显示消息内容。
- 代码：`scripts/passport_feishu.py`（读取和过滤，自带自检），`passport_services.py` 的 `feishu_loop` 和 `feishu_page`。

## 用户要做的设置

1. 系统设置 › 隐私与安全性 › 完全磁盘访问权限：打开 AI Passport Assistant。没打开时，胸牌页面和设置网页都显示「需要完全磁盘访问权限」。
2. 飞书 › 设置 › 通知：允许系统通知，并显示消息详情。

## 功能

- **任意页面提醒**：底部栏显示「飞书·谁：消息开头」，同时亮屏。普通消息显示 8 秒（蓝色），特别关注 20 秒（红色）。番茄钟专注时只提醒特别关注。
- **飞书提醒页**：最近 6 条，新到的带蓝点，特别关注显示红名；顶部是今天的条数和提醒方式。

  | 按键 | 列表 | 打开的消息 |
  | --- | --- | --- |
  | 上 / 下 | 选择 | 上一条 / 下一条 |
  | 确认 | 查看详情 | 朗读 |
  | 长按上 | 在电脑上打开飞书 | |
  | 长按下 | 切换提醒方式：全部 → 只提醒特别关注 → 不提醒 | |
  | 长按确认 | 返回 | 返回列表 |

  也可以说「你好小智」，然后说「飞书」。
- **朗读**：在详情里按确认，胸牌自己用百度语音读「谁说：消息」，需要胸牌能联网（WiFi，或 USB 连电脑时的 PPP）。蓝牙下朗读时会临时断开蓝牙腾出内存，读完自动重连。
- **设置网页**（助手 › 网页设置 › 飞书提醒）：提醒方式、特别关注（名字或关键词）、不提醒（名字或群名，页面里仍然列出）、「发一条测试提醒」（测试消息也会出现在胸牌列表里，可以试朗读）。

## 限制

- 只能看到通知里的内容，长消息只有开头（最多 48 个字），看不到完整聊天记录，也不能回复。
- 你正在看飞书窗口时，飞书不发系统通知，胸牌也收不到。
- USB 连接时任何页面都能收到提醒；只连蓝牙时，胸牌在联网页面（例如主页）会关掉蓝牙省内存，所以要停在「飞书提醒」页才收得到。
- 只支持 Mac。Windows 版飞书的通知还没有调研，页面显示「暂只支持 Mac」。
- 特别关注靠名字和关键词匹配；飞书 @我 的通知格式还没确认，可以先把自己的名字加进特别关注。
- 底部提醒和「打开电脑程序」共用一块 64 字节的显示区（聊天页的内存余量只剩几百字节），所以提醒里消息只显示前十几个字，完整的开头在飞书提醒页看。

## 验证

- `python3 scripts/passport_feishu.py`：用假的通知数据库自检读取、过滤、特别关注、不提醒、关闭提醒、今天条数、测试消息。
- C3 仿真 `CASE_PASS feishu`：列表、打开、上下翻、返回、进页面清空、底部提醒；截图 `releases/menu-customization-test/feishu_*.png`。
- 真机（2026-11-03，USB）：在主页收到测试提醒；进入飞书提醒页读到这台 Mac 上的历史飞书通知；朗读测试消息成功（HTTP 200，播放约 47 KB）；长按下切换三种提醒方式；停在页面时来提醒会自动刷新。
- 没有在真机上验证：真实新消息到达（测试时没有新飞书消息）、蓝牙下的提醒和朗读、长按上打开飞书（只确认了能找到 Lark.app）。
