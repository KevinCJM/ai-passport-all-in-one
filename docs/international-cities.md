# 海外城市支持（0.5.23）

胸牌原有 364 个中国城市条目继续保留，新增 155 个海外常用城市，共 519 项；覆盖美国 24、加拿大 12、日本 14、韩国 9、澳大利亚 8，以及欧洲 46 个国家或地区的 88 个城市。手机页保留原有中国常用城市列表，加入相同的 155 个海外城市，共 201 项。并非每个国家的所有城市都内置；IP 定位不受内置城市表限制。

## 使用

1. 胸牌进入「系统设置 › 所在城市」，选择「语音输入城市」，确认后说「美国纽约」「加拿大温哥华」「日本东京」等，说完按确认。支持中英文名及常见别名，如「三藩市」「雪梨」；同名城市请加国家，如「英国伦敦」「加拿大伦敦」，单说「伦敦」默认英国。
2. 或选择「按 IP 定位」并确认，使用当前 WiFi 或 USB PPP 网络出口的城市和实际坐标。代理、VPN、运营商出口可能让结果偏离所在地；可改用语音或手机选择。这是 IP 城市定位，不是 GPS。
3. 手机进入胸牌配置网页的「收听」，按城市中文、英文或国家筛选，选择具体城市后保存。入口仍为「系统设置 › WiFi 配置 › 添加 WiFi」，连接屏幕显示的设备热点后打开 `http://192.168.8.1`。筛选在手机本地完成，不要求手机联网。通过 IP 保存的表外城市会保留在下拉框中。

天气预报的「今天」、星期、小时、日出和日落按所选城市当地时间。主时钟、闹钟、待办时间仍沿用原有系统时区，默认北京时间，不会因换城市改变。空气质量继续统一按中国国标换算，页面标明「国标」；气象预警只覆盖中国内地。海外城市使用已有全国和网络电台，不新增海外本地电台。

## 实现与兼容

- `data/international-cities.json` 是海外城市坐标、中文名、国家和别名的唯一维护源。运行 `python3 scripts/generate_passport_cities.py` 同步生成语音条目、国家表及手机页数据，`--check` 检查是否同步。
- 内置表为只读 Flash 数据，无联网搜索任务和常驻结果缓存。`MediaPrefs` 仍为 v2、140 字节，原有城市与菜单 NVS 配置兼容。
- 手机保存和原生定位共用国家码格式、坐标范围与字段长度校验；失败不覆盖旧城市。IP 名称按国家匹配，坐标始终采用服务返回值；网页读取、搜索和再次保存也保留当前坐标，避免把美国缅因州波特兰误改为俄勒冈州波特兰。
- 预报新增 `wd` 字段传递查询城市第一天的星期。按服务返回的 ISO 日期计算，不使用胸牌系统日期推算，支持日期变更线和夏令时边界；旧消息缺少该字段时显示「第 N 天」。

城市坐标来自 [GeoNames cities15000](https://download.geonames.org/export/dump/)，按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 使用；中文名和别名经过整理。已有城市数据的 GeoNames 署名继续保留。天气沿用 [Open-Meteo Forecast API](https://open-meteo.com/en/docs)，`timezone=auto` 返回查询城市当地时间。IP 定位沿用无需密钥的 [ip-api JSON 接口](https://ip-api.com/docs/api:json)，由用户在胸牌主动触发，未增加后台定位。

## 验证

```sh
python3 tests/test_passport_cities.py -v
node scripts/test_passport_cities_browser.mjs
bash scripts/build_passport_suite.sh
python3 scripts/test_passport_cities_sim.py
bash scripts/build_passport_suite.sh device
```

宿主测试编译实际原生定位和语音方法，覆盖国家与同名城市、表外城市、失败保留旧值、坐标校验和跨时区日期，并使用 ASan/UBSan。浏览器测试使用隔离的 Chrome 和模拟设备接口，验证手机页搜索、保存与无结果保护；不连接实机。C3 模拟器逐一检查全部 519 个城市的坐标和字形，保存真实 LVGL 像素。测试材料在 `releases/city-support-test/`；编译和模拟器结果不能替代实际语音识别、按键与网络验收。
