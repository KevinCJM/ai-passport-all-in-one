## 指标与计算口径

| 指标 | FRED 代码 | 显示值 | 频率 |
| --- | --- | --- | --- |
| 联邦基金利率（默认） | DFF | 有效利率，% | 日 |
| 两年美债（默认） | DGS2 | 收益率，% | 日 |
| 十年美债（默认） | DGS10 | 收益率，% | 日 |
| 美债期限利差（默认） | T10Y2Y | 十年减两年，原始百分点乘 100，bp | 日 |
| 美国 CPI 同比（默认） | CPIAUCNS | 未季调指数的同比，% | 月 |
| 美国失业率（默认） | UNRATE | 季调失业率，% | 月 |
| 核心 CPI 同比 | CPILFENS | 未季调核心 CPI 指数的同比，% | 月 |
| 核心 PCE 同比 | PCEPILFE | 季调核心 PCE 价格指数的同比，% | 月 |
| 非农新增就业 | PAYEMS | 季调就业人数的月差；原始千人差除以 10，万人 | 月 |
| 初请失业金 | ICSA | 季调初请人数除以 1000，千人 | 周 |
| 实际 GDP 增速 | A191RL1Q225SBEA | 季调实际 GDP 环比折年率，% | 季 |
| 美元广义指数 | DTWEXBGS | 贸易加权广义美元指数，点；与 DXY 口径不同 | 日 |
| 美国 M2 同比 | M2SL | 季调 M2 的同比，% | 月 |
| 三十年美债 | DGS30 | 收益率，% | 日 |

同比 = `(本月 / 去年同月 - 1) × 100`。计算必须找到同一月份的有效基数；缺月或基数为零时不生成同比。非农新增必须找到上一个日历月，不跨缺月计算。节假日空值跳过，不代表数值为零。

利率变化显示 bp，`4.20% → 4.25%` 显示 `+5.0bp`；CPI 同比 `3.0% → 3.2%` 显示 `+0.20百分点`。人数与指数显示原单位的差。趋势图没有蜡烛图或交易时段；相邻点代表相邻有效观测。

“数据日期”来自 FRED 观测所属日期，不是抓取时间。例如月度值通常以该月一日标记，季度值以季度首日标记，不把它当作公布日。首版没有公布日提醒或市场预期值。离线、部分更新失败会在页面提示；来源修订数值后，下次刷新采用修订值。

## 数据与资源

- 数据源：FRED 官方站点的公共 CSV 下载 `https://fred.stlouisfed.org/graph/fredgraph.csv?id=<代码>&cosd=<起始日期>`。这是网站下载端点，区别于需要 Key 的 FRED REST API；若站点下载规则变化，需要调整适配。
- 本机探测 14 项均返回 HTTP 200，响应通过同一 C++ 解析器。此证据只覆盖本机网络，不代表 ESP32 的 TLS、网络可达性或语音闭环通过。
- HTTPS 校验证书，复用原生联网任务；CSV 按块读取，单行最多 95 字节，最多保存 60 个有效点。错误页、错系列、非法日期、乱序和无效数字不提交为新数据。
- 消息只传目录编号、数值、日期与归一化趋势点，复用已有 2 KiB 消息通道。数据放入现有页面 union，避免所有应用各占一份常驻内存。
- NVS 键为 `media/macro_list` 与 `media/macro_cache`。普通刷新不因抓取时间改变而重复保存相同列表数据；数据变化或缓存新趋势时保存。
- 语音识别复用现有小智连接与凭据。行情抓取和离线浏览不要求 Mac 助手，不增加图片、解码器或常驻后台任务。

官方口径可核对 [DFF](https://fred.stlouisfed.org/series/DFF)、[DGS10](https://fred.stlouisfed.org/series/DGS10)、[CPIAUCNS](https://fred.stlouisfed.org/series/CPIAUCNS)、[PAYEMS](https://fred.stlouisfed.org/series/PAYEMS)。FRED 正式 API 参见[观测数据文档](https://fred.stlouisfed.org/docs/api/fred/series_observations.html)。

### 0.5.18 下载兼容修复

PPP 可正常收发时，宏观请求仍可能在读取响应头时返回 `ESP_ERR_HTTP_EAGAIN`（`0x7007`）。2026-10-30 同出口直连对照中，FRED 的同一 CSV 地址使用 SDK 默认客户端标识时超时，使用 curl 兼容标识时返回 HTTP 200；这定位到下载请求兼容问题，不能据此确认服务端的具体过滤规则。
