# 记分牌

固件 0.5.30 新增，App 编号 48（`App::Score`），在菜单「工具 · 设置」页（系统设置前面）。离线功能，不用联网，也不用电脑。

## 用法

| 按键 | 作用 |
| --- | --- |
| 上 | 红方 +1（屏幕上半） |
| 下 | 蓝方 +1（屏幕下半） |
| 确认 | 撤销上一分；已结束的局或比赛也会撤回来 |
| 长按上 / 长按下 | 还没得分时：换到下一个 / 上一个赛制。比赛进行中长按上会提示先重开 |
| 长按下 | 有分数时：第一次提示「再长按下键：清零重开」，再长按一次才清零。中间按其他键就取消 |

**多人计分（3–8 人）** 按键不同：

| 按键 | 作用 |
| --- | --- |
| 上 / 下 | 选人（选中的卡片有彩色边框） |
| 确认 | 选中的人 +1 |
| 长按上 | 撤销上一分（提示撤销了谁的分）；还没得分时换赛制 |
| 长按下 | 两次清零重开；还没得分时换赛制 |
| 长按确认 | 返回 |

也可以喊「你好小智」，然后说「记分牌」「计分」或「比分」直接打开。

## 赛制

| 赛制 | 一局 | 比赛 | 发球提示 |
| --- | --- | --- | --- |
| 自由计分 | 不分局，0–999 | — | 无 |
| 乒乓球 | 11 分，领先 2 分 | 5 局 3 胜 | 每人 2 球；10 平后 1 球一换；每局轮换先发 |
| 羽毛球 | 21 分，领先 2 分，30 分封顶 | 3 局 2 胜 | 得分方发球；上一局赢家先发 |
| 排球 | 25 分，领先 2 分；决胜局 15 分 | 5 局 3 胜 | 得分方发球；每局轮换先发 |
| 多人计分 · 3–8 人 | 不分局，每人 0–999 | — | 无 |

- 赛制顺序：自由计分 → 乒乓球 → 羽毛球 → 排球 → 多人 3 人 → … → 8 人，再回到自由计分。长按下往回走，所以从自由计分长按下一次就是 8 人。
- 多人计分：红、蓝、绿、黄、紫、橙、青、粉 8 种颜色。4 人以内一列大卡片，5 人以上两列。分数唯一最高的人标「领先」。

- 屏幕显示：赛制、第几局、每方局分、发球方、「局点」或「赛点」。
- 一局结束时提示「红方拿下第 1 局 11:9」，底部列出各局比分。
- 比赛结束后，大数字改为显示局分，并标出「获胜」；这时再加分会被拒绝，可以撤销或重开。
- 分数用七段数码管样式的大数字绘制，隔着桌子也能看清。

## 设计

- **只存得分顺序。** `ScoreBoard`（`score.hpp`，84 字节）记录每一分是谁得的（双方 1 bit 一分，最多 512 分；多人 4 bit 一分，最多 128 分）。局分、发球、局点和历史比分都由 `scoreReplay()` 按赛制回放算出，所以撤销就是删掉最后一位，局和比赛结束也能撤回。
- **每得一分写一次 NVS**（`suite_system/score_v2`；旧的 `score_v1` 升级后不再读取，进行中的比分会清零），休眠、断电或切到别的页面都不会丢比分。512 分足够任何一场有赛制的比赛；超出会提示「记录已满」。自由计分和多人计分记满后，把最早一个字节的分折进底数（`base[8]`），继续计数，只是不能撤销那么久以前的分。
- 不改变息屏和睡眠规则：按自动息屏设置照常熄屏，比分已经保存。
- 数据放在页面共用的 `Model::page` union 里，只额外占用 2 字节 RAM（`scoreArmed`、`scorePick`）。固件增加约 4 KB。

## 改动位置

- `firmware/passport_suite/main/score.hpp`：赛制表、回放、加分和撤销，纯逻辑。
- `suite.cpp`：按键处理和长按处理；进入页面时读取 NVS。
- `ui.cpp`：`drawScore` 自绘页面。
- `key_hints.hpp`：底部按键提示。
- `voice_add.hpp`：语音跳转用的词。
- `apps.hpp`：菜单位置。
- `settings.*`：`loadScore` 和 `saveScore`。
- `passport_connectivity/main/main.cpp`：把长按交给页面处理。
- `generate_passport_font.py`：新增奖杯图标 U+E00C（Font Awesome 5 Free）。
- 菜单从 43 项增加到 44 项。已保存过自定义菜单的用户，升级后新功能按 `MenuLayout::upgrade()` 追加到菜单里并默认显示。

## 以后可以加（目前没做）

- 队名 / 人名：在手机配置页或电脑助手里修改（现在多人用颜色区分）。
- 多人计分的扣分或一次加多分（如斗地主、麻将）。现在只能 +1 和撤销。
- 更多赛制：网球（15/30/40、抢七）和匹克球（换发计分）规则复杂，需要单独实现。
- 篮球的 +2 和 +3。现在可以用自由计分多按几次代替。
- 比赛中保持常亮的开关，类似状态牌的「常亮」。
